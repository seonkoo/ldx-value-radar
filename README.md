# 李大霄价值投资雷达 · 蓝筹逆向布局

基于《李大霄投资战略》核心理念，对 **沪深300 蓝筹股**做长线价值筛选的静态网页工具。
不做 K 线、不做量价、不做指标回测 —— 只回答一个问题：

> 现在大盘估值在什么位置？哪些低估蓝筹值得分批逆向下手？

⚠️ **本项目仅为书中观点的量化梳理与工具化实现，不构成任何投资建议。**

---

## 一、它怎么选股

### 1. 先排雷：硬排除「黑五类」

| 类型 | 判定规则 |
|---|---|
| 小盘股 | 总市值 < 200 亿 |
| 次新股 | 连续现金分红 < 5 年 |
| 垃圾股 | PE ≤ 0（亏损） |
| 题材股 / 伪成长股 | PE > 50 倍 |
| 不派息 | 近 12 个月无现金分红 |

沪深300 的 288 只成分股，实际通过 **185 只**，排除 103 只。

### 2. 再打分：四维加权（分位排名，合计 100 分）

| 维度 | 权重 | 方向 |
|---|---|---|
| 股息率 | 35% | 越高越好（最看重"得好报"） |
| 低 PE | 25% | 越低越好 |
| 低 PB | 25% | 越低越好，破净最优 |
| 分红稳定性 | 15% | 近 N 年年报派息的变异系数倒数 |

### 3. 择时：沪深300 估值历史分位

| 分位 | 信号 | 建议仓位 | 动作 |
|---|---|---|---|
| < 20% | 钻石底 | 70-80% | 逆向重仓，正金字塔大举建仓 |
| 20-35% | 婴儿底 / 偏低 | 50-65% | 分批加仓，越跌越买 |
| 35-65% | 正常 | 30-45% | 持有为主，不满仓 |
| 65-85% | 偏热 | 10-25% | 逐步减仓 |
| > 85% | 地球顶 | 0-10% | 淡泊离场 |

择时三要素：**估值水平**（乐咕沪深300 历史 PE，2005 年至今）+ **产业资本动向**（股东增减持）+ **市场情绪**（破净股占比等自建指标）。

#### 估值的降级兜底

乐咕（`stock_index_pe_lg`）是唯一覆盖 2005 年至今的长历史数据源，但**偶发被反爬拦截返回非 JSON**。
它一旦拿不到，温度计和仓位建议就会全部失效 —— 所以加了两层保护：

1. 连续重试 3 次（间隔 2s / 4s）
2. 仍失败则读 `data/valuation_cache.json` 的历史序列，按实时指数点位推算当前 PE

推算依据是 **PE 与指数点位成正比**（成分股盈利短期可视作不变）：

```
当前PE ≈ 缓存时PE × (当前点位 / 缓存时点位)
```

缓存每次主路径成功时自动刷新，并由 CI 提交回仓库以跨 run 持久化。
降级时页面会在温度计下方显示黄色提示条，**不会静默给出错误信号**。

### 4. 八步财报深度分析（仅 TOP 30）

| 步骤 | 性质 | 内容 |
|---|---|---|
| ① 业务与商业模式 | 定性 | 5 条人工研读检查清单（机器无法打分） |
| ② 三张报表 | 可量化 | ROE/毛利率/净利率/扣非比/资产负债率/商誉/现金含量/营收增速/净利增速 + 规模条 |
| ③ 公司治理与管理层 | 半量化 | 增减持净向 + 5 条治理检查清单 |
| ④ 资本行为 | 可量化 | 股息率/连续分红/分红稳定性 + 回购核查说明 |
| ⑤ 估值对比 | 可量化 | 当前 PE/PB + 自身近三年历史分位（与同行对比见 ⑦） |
| ⑥ 驱动因素与风险 | 半量化 | 量化风险清单 + 5 条驱动因素检查清单 |
| ⑦ 行业与竞争格局 | 半量化 | 所属行业 + 5 条竞争格局检查清单 |
| ⑧ 情景测算 | 可量化 | 悲观/中性/乐观三档价格推演 + 测算基准 |

> **设计原则**：定性问题机器不强行打分，只给检查清单 —— 数据可以给，判断得你自己下。
> 金融业（银行/保险/证券）在「资产负债率 / 商誉 / 现金流」三项自动标记为「不适用」，避免行业差异误判。

## 二、数据口径（重要）

### 股息率
```
股息率 = 近 12 个月内【已完成除权】的每股派息合计 ÷ 当前股价
```
- 含中期分红，剔除未实施预案（除权除息日为空的方案不计）
- 这是 TTM 口径，与部分行情软件按单一报告期折算的结果**会有差异**
- 因此可能出现：某股 12 个月内恰好派了两次年度分红，股息率显著高于其"年度分红率"（属正常现象，非计算错误）

### 连续分红年
自最新年份向前回溯，年报（12-31 报告期）连续有现金分红的年数。数据回溯 6 个年份，可区分「恰好 5 年」与「超过 5 年」。

### 数据来源

| 项目 | 来源 | 说明 |
|---|---|---|
| 蓝筹池 | 中证指数（沪深300 成分股） | 288 只 |
| 行情估值 | 腾讯行情 | PE(TTM) / PB / 总市值，已与百度估值交叉校验（10 只抽检 9 只完全一致） |
| 分红派息 | 东方财富 分红送配 | 11 个报告期 |
| 大盘估值分位 | 乐咕乐股 | 沪深300 滚动 PE，257 个月度样本；失败时由本地缓存 + 腾讯指数点位降级推算 |
| 产业资本 | 东方财富 股东增减持 | 全量样本后按池内过滤 |
| 三张报表（深度） | 新浪财经 财务摘要 | 80 项指标 × 多期；现金流 / 资产负债率按年报口径取 |
| 个股历史估值（深度） | 百度股市通 | 近三年日级 PE/PB 序列（~1096 点） |
| 行业归属（深度） | 新浪财经 行业板块 | 84 个行业，证监会 CSRC 分类 |

## 三、本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 生成数据（约 100 秒）
python scripts/build_data.py

# 起本地服务（必须走 HTTP，file:// 打开会被浏览器跨域策略拦住）
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

Windows 下同样适用（PowerShell / CMD 均可）。

## 四、部署到 GitHub Pages（每日自动更新）

### 1. 建仓库并推送

```bash
cd ldx-value-radar
git init
git add .
git commit -m "init: 李大霄价值投资雷达"
git branch -M main
git remote add origin https://github.com/<你的用户名>/ldx-value-radar.git
git push -u origin main
```

### 2. 开启 Pages

仓库 **Settings → Pages → Build and deployment**
- Source 选 **Deploy from a branch**
- Branch 选 **main** / 根目录 `/`

### 3. 每日自动更新

`.github/workflows/daily.yml` 已配置：

- **工作日 18:00（北京时间）**自动执行（cron 用 UTC，写作 `0 10 * * 1-5`）
- 跑完校验数据条目 ≥ 50，异常则拒绝提交
- 数据有变化才 commit，无变化跳过
- 同时上传 artifact 备份，保留 7 天

也可在 Actions 页面点 **Run workflow** 手动触发。

> **刻意没有监听 `push` 事件**：改代码时不需要重跑约 100 秒的数据抓取，省 Actions 额度。
> 想刷新数据时手动 Run workflow 即可。

Actions 需要仓库有写权限（首次部署后检查一次）：
**Settings → Actions → General → Workflow permissions → Read and write permissions**

## 六、几个需要知道的点

1. **和短线体系不要混用**。这是大周期底部区域的长线逆向布局工具，和 D 点、放量滞胀那套短线择时逻辑完全不同，两者混用会互相干扰。

2. **评分是相对排名，不是绝对估值判断**。分位得分只说明该股在通过筛选的 185 只蓝筹中的相对位置。

3. **PE 历史分位存在口径差异**。乐咕与中证官网的沪深300 PE 因计算方法（整体法 / 中位数法）不同会有偏差，本工具统一采用乐咕口径。

4. **每日收盘后更新，非盘中实时**。
